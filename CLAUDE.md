# tarot

A small static site (two pages) covering three complete public-domain
tarot decks, each with its original scanned/engraved card art: a draw
page, and a full-deck reference page.

## Pages
- **`index.html` (Draw)** — deck-picker buttons, a "reversed cards" on/off toggle, a flip-card element (image fills the whole frame, edge to edge), a caption block below the card (number/name/orientation/meaning), and a "Draw a card" button. No subtitle text and no art-source credit line — both were deliberately removed.
- **`deck.html` (Full Deck)** — the same deck-picker buttons, then a responsive grid of every card in the selected deck: thumbnail, number, name, and both upright/reversed meanings, all shown at once (a reference/browse page, not the draw interaction). Built as the first of the "worth planning" pages below.
- Both pages share a `.site-nav` header (`Draw` / `Full Deck` links, hand-duplicated in each HTML file — no templating/build step exists to share it).

## Planned pages (not yet built)
The nav is meant to grow. Candidates, not yet started:
- **Spreads** — multi-card layouts (e.g. 3-card past/present/future, Celtic Cross) instead of a single draw.
- **About / sourcing** — since the on-page art credit was removed from the draw page, a dedicated page could hold the full Commons sourcing + license info that currently only lives in this file and `progress.md`.
- **Journal / history** — a local (localStorage-based, no backend exists) log of past draws.

## Structure
- `decks.js` — registry mapping a deck key (`egyptian`/`rws`/`solabusca`) to its display label and its `CARDS` array from the corresponding `cards-*.js` file. Loaded after the three `cards-*.js` files, before `script.js` or `deck-page.js`.
- `cards-egyptian.js` — 22-card `EGYPTIAN_CARDS` array (Falconnier & Wegener, 1896).
- `cards-rws.js` — 78-card `RWS_CARDS` array (Rider-Waite-Smith, 1909): 22 majors + 4×14 minors generated by the `rwsMinorSuit()` helper.
- `cards-solabusca.js` — 78-card `SOLABUSCA_CARDS` array (Sola Busca, 1491): 22 majors + 4×14 minors generated by the `solaMinorSuit()` helper.
- Every card entry has `name`, `num`, `img` (path under `images/`), `up`/`rev` (upright/reversed meaning keywords).
- `script.js` (draw page only) — builds the deck-picker buttons from `DECKS`, draw logic (random card from whichever deck is selected; reversed only possible when `#reversed-toggle` is checked), flips the card, swaps in the image and caption text.
- `deck-page.js` (full-deck page only) — builds the same deck-picker buttons, then renders every card in the selected deck as a grid item with both meanings visible.
- `style.css` — dark/gold mystical theme shared by both pages: 3D flip animation, full-bleed card image (`object-fit: cover`), pill-style deck buttons, nav styling, the reversed-toggle checkbox, the full-deck grid, responsive down to phone width.
- `images/egyptian/01.png`–`22.png`, `images/rws/major_00.jpg`…`wands_14.jpg` etc., `images/solabusca/00.jpg`–`77.jpg` — the three decks' original art, all public domain, all downloaded from Wikimedia Commons (~38MB total across all three decks).

## Deck details & sourcing
- **Egyptian (Falconnier & Wegener, 1896)** — 22 cards only; the historical Egyptian Tarot never had a Minor Arcana. Source: Commons `Category:Egyptian_Tarot_(Falconnier)`.
- **Rider-Waite-Smith (1909)** — 78 cards, the modern standard; every minor-arcana card is a full illustrated scene, not just suit pips. Source: Commons `Category:Rider-Waite_tarot_deck_(Roses_%26_Lilies)`, files named `RWS1909 - <card>.jpeg`.
- **Sola Busca (1491)** — 78 cards, the oldest complete surviving tarot deck and the first with illustrated (not just pip) suit cards. Source: Commons `Category:Sola-Busca_tarot_deck`, files `Sola Busca tarot card 00.jpg` through `77.jpg`.
  - The 22 trumps have unique Renaissance names (Mato, Panfilio, Nabuchodenasor, ...) rather than the familiar tarot titles; `cards-solabusca.js` labels each as `"<name> (<standard equivalent>)"`.
  - Sola Busca follows the **Tarot de Marseille** trump ordering (Justice = 8th trump, Strength = 11th), not the Rider-Waite-Smith ordering (which swapped those two) — this matters for anyone extending the meanings.
  - Suit-card block order within the 78 was verified by visually inspecting sample images (ace/rank markings), not assumed: files 00-21 = trumps, 22-35 = Cups, 36-49 = Pentacles (Coins), 50-63 = Wands (Batons), 64-77 = Swords, each block Ace→10→Page→Knight→Queen→King.
  - The 56 suit cards do carry their own unique inscribed court-card names (e.g. the Knight of Cups is "Natanabo"), but are labeled here by standard suit+rank for consistency with the other two decks — the real inscribed names are visible in the artwork itself.
  - Minor-arcana meanings for both RWS and Sola Busca reuse the same standard keyword set (structurally equivalent positions), since Sola Busca has no independent, widely-documented divinatory tradition of its own.

## Conventions
- No build step, no dependencies — plain HTML/CSS/JS, open `index.html` directly or serve statically.
- English UI by default per the standing no-Russian-unless-specified rule, even though every request that built this site was in Russian.
- Reversed cards are rendered by rotating the whole card face 180° (not just re-labeling it) so the image itself appears upside-down, matching how a physical reversed card looks.
- All card art is verified public domain and sourced from Wikimedia Commons (sourcing details are tracked here in CLAUDE.md, not shown on-page — the user asked for the on-page credit line to be removed).
